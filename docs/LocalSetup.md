# Local Setup (Mac)

The repository contains an initial Laravel/Inertia application foundation. It has not yet been installed and smoke-tested on the target Mac.

## Requirements
PHP 8.2+, Composer 2, Node 20+, npm, SQLite PHP extension, and Git. Python, FFmpeg, Remotion and Piper are later milestones.

## Start the app
```bash
git clone https://github.com/mrseewhy/veyora-media-engine.git
cd veyora-media-engine
git checkout feat/app-foundation
composer install
npm install
cp .env.example .env
touch database/database.sqlite
php artisan key:generate
php artisan migrate --seed
php artisan app:create-admin
```

Run in separate terminals:
```bash
php artisan serve
npm run dev
php artisan queue:work --tries=3
```

Visit http://localhost:8000 and sign in with the admin account you created.

## Verify
```bash
php artisan test
npm run typecheck
npm run build
```

Do **not** commit the .env file, generated SQLite database, generated media, OAuth credentials or provider tokens. Inertia/Vite build files are generated by npm. Run code inspections and smoke tests before merging this foundation branch to main.

## Troubleshooting
- If Composer reports missing PHP extensions, enable SQLite/PDO and mbstring.
- If the queue seems stuck, confirm `php artisan queue:work` is running and DB tables exist.
- If the browser shows a Vite manifest error, start `npm run dev` or build assets.
- If the initial admin is missing, run `php artisan app:create-admin` again after migration; it refuses to create a second account.
